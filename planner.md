# Gluster Planning Document

**GOAL**: Gluster is intended to be a cluster/multi pc managment system for tasks and commands

Think REDIS but designed for homelabs and their desired tasks.

Gluster is meant to be run on all devices that are meant to be in the cluster, with one main orchestrator gluster instance, then all the worker instances.


## Current status of the application:
- [x] Device registration
- [x] Tasks list system
- [ ] Task cost calculator (damn near impossible for now)
- [ ] Over the air send and run tasks (gin api)
